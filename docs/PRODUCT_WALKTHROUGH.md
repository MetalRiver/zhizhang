# 智账 · 产品使用指南

打开智账后，左侧有 7 个入口。以下按普通用户的使用场景逐一说明。

## 总览

第一眼看的页面。核心指标叠在其上：总 Token 用量、数据源数、
API 等价估算成本（多币种分列，不做汇率换算）、模型数、账本事件数。

右栏可看 30 天 Token 趋势、模型使用占比、最近巡检任务。
底部是实时动态链和 1/7/30/90 天时间档。

成本 KPI 副文案会告诉你 Token 覆盖率（当前 99.3%+）——即有多少比例的
用量已经被定价覆盖。如果看到「已剔除 N 条重放」，表示 EFFECTIVE 口径
已自动去掉了 dsh 血统重放的重复计数。

## 数据源

告诉你账本从哪里拿数据。5 个来源对应你机器上的 5 个 AI 客户端：

- **ZCode / dsh / WorkBuddy** 标为 TOKEN——它们本地记录了真实 token 用量
- **CatPaw / Trae CN** 标为 ACTIVITY——只记活动痕迹，没有 token 数据

每个来源有记录数、现存/已清退文件数、路径提示（脱敏）。
底部有「不透明存储」——已识别但加密读不出来的库（如 Trae CN 的
ai-agent 数据库），登记为 UNKNOWN。

## 客户端

每个 AI 客户端的有效用量画像卡片：类型、有效请求、输入/输出/缓存读取、
日期范围。如果某客户端有已验证重放（如 dsh），卡片里会额外显示
RAW / Replay / Effective 三个数字——让你知道去重前后的差别。

ACTIVITY 类客户端（CatPaw / Trae CN）显示 Activity records 和 Sessions，
不是 0 Token——因为它们本地确实没有 token 数据。

## 模型与成本

按模型列出有效用量与 API 等价估算成本。顶部三张卡：CNY 等价估算总额、
USD 等价估算总额、Usage pricing coverage（Token 覆盖率百分比）。

每行是一个模型：名称、Provider、请求数、输入/输出/缓存读取（tooltip
显示完整值）、成本（币种符号标注）、定价来源 badge（人工确认=金色 /
目录候选=青色 / 未定价=灰色）。未定价的模型显示「未定价」而不是 $0。

搜索框可以过滤模型名。

## 巡检任务

系统当前运行健康状态一览：

- **Data Health**：数据链路是否正常（partial = 部分模型未定价）
- **Local API**：本地 API 是否连接
- **Last Scan**：最近一次采集的时间和结果
- **Scheduler**：自动调度是否启用（本机如被策略拦截会显示 unavailable）
- **Pricing Coverage**：Token 覆盖率
- **Replay Validation**：dsh 重放验证结果
- **Opaque Stores**：加密不可读的存储

底部有最近错误/警告列表。

## 使用明细

按日聚合的有效用量表格。可以按客户端筛选。默认 EFFECTIVE 口径
（重放已剔除）。

切换「RAW 审计」可看完整账本汇总（含重放数字），但仅供审计——
当前版本不提供 RAW 按日时间序列。

## 系统设置

只读状态页：产品版本、Board Schema 版本、成本语义（API 等价估算）、
默认口径（EFFECTIVE）、隐私声明（路径脱敏、无 event_id）、数据窗口、
健康状态、DB 版本。不提供删除或危险操作。
