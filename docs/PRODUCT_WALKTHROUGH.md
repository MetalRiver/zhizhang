# 智账 · 产品使用指南

> 本指南对应 **0.11.0-rc.7** 的正式桌面界面：
> 左侧三个入口——**总览 / 探索 / 设置**。
> 所有数据只保存在本机；已入账的记录，即使工具清理了原始历史也依然保留。

## 界面总览

- **总览**：回答"最近 AI 都用在哪"——项目、会话、用量与估算成本一屏掌握。
- **探索**：从项目找到会话，再看每一次 AI 使用的逐条记录（支持审计口径切换）。
- **设置**：更新账本、管理 AI 工具、项目整理、数据位置与迁移、隐私与高级说明。

## 首次使用

首次启动会进入四步引导：**欢迎 → 偏好 → 找到 AI 工具 → 建立账本**。

1. 选择账本保存位置（系统推荐位置，或本机自选文件夹，支持中文路径）；
2. 选择后台偏好（托盘驻留 / 开机自启，可随时在设置中更改）；
3. 智账自动检查本机支持的 AI 工具（只读标准安装位置，不搜索整台电脑）；
4. 确认发现结果后点击「建立我的账本」完成首次读取。

完成后进入总览。部分工具只有使用痕迹、部分用量暂无价格——
这些差异界面都会如实说明，不会算成「免费」或「没有使用」。

## 总览

- **指标区**：参与的项目数、AI 会话数、AI 使用量、估算成本
  （成本副文案始终标注「API 等价值估算 · 不是实际账单」，
  人民币 / 美元分别显示、不换汇；无法估算时如实显示「暂不能估算」）。
- **我的项目**：按项目列出会话数、使用量、估算成本与账本状态
  （「已读取用量」/「只能确认使用过」）；可按使用量、人民币 / 美元估算、
  最近使用排序。点击任意项目打开项目抽屉：
  查看汇总、参与工具、项目会话列表，可**修改项目名称**、**整理项目**
  （把会话归入正确的项目）。
- **这本账完整吗？**（右栏）：按工具汇总数据完整性——多少工具可读取
  完整用量、多少存在历史缺口、多少只能确认使用过，
  以及价格覆盖情况。点击「查看详情」打开**数据完整性**报告
  （详见下文「数据完整性与来源状态」）。
- **最近的使用变化**：近 14 天已读取用量的趋势。
- **最近的 AI 会话**：可直接跳转到探索页查看完整使用记录。
- **想看看用了哪些模型？**：展开可按使用量查看模型分布与定价来源
  （用户配置 / 官方 API 价 / 第三方参考价 / 暂无可靠价格）。

时间范围可在工具栏切换（今天 / 最近 7 天 / 最近 30 天 / 全部历史）。

## 探索

探索页按 **项目 → 会话 → 事件** 三层下钻：

1. 顶部选择项目（或「全部」）；
2. 中部选择会话：查看该会话的所属项目、时间、AI 工具、模型与用量汇总，
   以及最近的使用记录；
3. 打开任一条记录查看**事件详情**：发生时间、工具、模型、
   输入 / 输出 / 缓存用量与成本估算。

右上角可切换**审计口径**：

- **EFFECTIVE（默认）**：剔除已确认的重复回放，日常查看用这个口径；
- **RAW（含重复回放）**：完整账本，仅供审计，估算成本 ≠ 实际账单；
- **REPLAY**：查看被标记的重放记录。

已入账的历史不会因为重新读取而丢失或重复计数：
同一份使用记录即使文件被移动、改名或恢复，也只记一次。

## 设置

设置页分七组：

| 分组 | 内容 |
|---|---|
| 常用 | 快速更新账本（读取最新使用记录）、后台与启动（托盘 / 开机自启）、账本状态、数据位置（打开数据目录） |
| AI 工具 | 这台电脑上发现了哪些 AI 工具、各自的数据等级；可「重新发现」 |
| 更新账本 | 手动从本机 AI 工具读取最新使用记录；最近一次更新的来源与结果 |
| 项目整理 | 把不同 AI 工具的使用整理到真正属于它的项目（改名 / 归组 / 合并） |
| 数据与隐私 | **账本保存位置**（打开文件夹 / 更改位置）、隐私声明（不上传完整路径、无遥测、无云同步）、历史账本说明 |
| 关于 | 版本信息；软件更新（默认启动时自动检查，可关闭；签名验证，验签失败拒绝安装） |
| 高级 | 面向高级用户的技术说明 |

注意：**「打开应用时自动更新」在 RC.6 尚未开放**，更新账本请使用手动入口
（设置 → 常用 / 更新账本、总览页的更新提示、托盘菜单「更新账本」）。

## 数据完整性与来源状态

智账按工具如实标注数据等级：

- **完整用量（TOKEN）**：本地记录了真实 token 用量（如 ZCode、Codex、
  WorkBuddy、dsh）；
- **活动量（ACTIVITY）**：只有使用痕迹，没有 token 字段
  （如 CatPaw、Trae CN）——只计活动，不计入 token 与成本；
- **无法读取（UNKNOWN）**：找到了存储但读不出内容（如 Trae CN 的加密
  数据库），如实登记，不猜测。

「数据完整性」报告还会说明：

- **历史缺口**：某些工具较早的记录格式无法计量，不会计入用量；
- **已清退的来源**：AI 工具清理了原始记录文件时，对应来源会标记
  已清退数量——**已经入账的历史仍然保留**；
- **成本覆盖**：可估算的用量比例；没有价格不等于免费；
- **更新前的历史**：首次更新之前、以及期间从未被读取过的记录，
  无法确认也无法恢复。

## 成本估算语义

- 成本 = **公开 API 参考价的等价估算**，不是实际账单；
  人民币 / 美元分别显示，不做汇率换算。
- 定价优先级：人工确认的配置 > 第三方参考目录；无法确认价格的模型
  显示「暂无可靠价格 · 未计入估算」，而不是 0。
- 口径：input 不含缓存；缓存命中单列；`total = input + output`。

## 账本位置与迁移

- 当前位置在 **设置 → 数据与隐私 → 账本保存位置** 中显示，可随时打开数据文件夹。
- 点击**更改位置**迁移账本：选择新的本机文件夹（要求为空文件夹；
  若目标已有一本智账账本，可选择改用它，当前账本原样保留）。
- 迁移期间账本更新暂停；复制与校验完成后才切换到新位置。
- **原位置的账本始终完整保留**；迁移失败时智账留在原账本上继续可用，
  并说明原因。若目标位置失联（如移动硬盘拔出），启动时会进入
  恢复界面，绝不会静默新建空账。

## 边界与限制（RC.6）

- 更新账本为**手动操作**，暂无自动定时更新；
- 仅支持列表中的本机客户端；**网页版 AI（ChatGPT、豆包、千问网页版等）
  的使用不在本机，目前无法记录**；
- RAW 口径用于审计查看；「项目整理」的人工归属会永久保留。
