# 智账 · 安装指南

> 本指南对应 **0.11.0-rc.7** 的正式发布产物与桌面界面。
> 安装包与便携包均可从
> [MetalRiver/zhizhang Releases](https://github.com/MetalRiver/zhizhang/releases) 下载。

## 系统要求

- Windows 10 / 11（x64）
- WebView2 Runtime（缺失时安装器会自动引导安装；便携版首次运行亦会处理）
- 无需安装 Python：全部依赖已随包提供

## 下载

发布页提供两种形态，任选其一：

| 形态 | 文件名（以 RC.6 为例） | 适合 |
|---|---|---|
| 安装版 | `zhizhang_0.11.0-rc.7_x64-setup.exe` | 日常使用，开始菜单启动 |
| 便携版 | `ZhiZhang-0.11.0-rc.7-win-x64-portable.zip` | 免安装、放在自选目录 |

每个版本附带 `SHA256SUMS.txt`（文件校验值）与 `latest.json`（应用内更新清单）。

## 安装版

1. 双击 `zhizhang_0.11.0-rc.7_x64-setup.exe`
2. 按向导完成安装（当前用户级安装，不需要管理员权限）
3. 从开始菜单打开「智账」

## 便携版

1. 解压 `ZhiZhang-0.11.0-rc.7-win-x64-portable.zip` 到任意目录
   （如 `D:\Tools\ZhiZhang\`，路径可含中文）
2. 双击目录中的 `UsageLedger.exe`，打开的是**桌面窗口**
   （后台核心位于 `binaries\` 子目录，会自动启动，无需手动操作）

## 首次启动：三步建立账本

首次启动会进入引导（欢迎 → 偏好 → 找到 AI 工具 → 建立账本）：

1. **选择账本保存位置**：默认使用系统推荐位置
   `%LOCALAPPDATA%\UsageLedger`，也可以选择其他本机文件夹
   （支持中文路径）。应用安装位置与账本位置相互独立，之后可在设置中安全迁移。
2. **选择后台偏好**（可跳过/后改）：关闭窗口后是否驻留系统托盘、
   是否开机自动启动。
3. **自动发现 AI 工具并建立账本**：智账会检查这台电脑上支持工具的
   标准安装位置（只读、不搜索整台电脑、不上传任何信息），
   发现结果确认后点击「建立我的账本」，完成首次读取。

之后随时手动更新账本即可把最新使用记录收入账本：
**设置 → 常用 →「读取最新使用记录」**、**设置 → 更新账本 →「立即更新」**，
或右键系统托盘图标选择「更新账本」
（打开应用时自动更新在 RC.6 尚未开放）。

## 支持的数据来源与限制

| 工具 | 记录内容 | 说明 |
|---|---|---|
| ZCode | 完整用量（token） | 本机 CLI 数据库 |
| Codex | 完整用量（token） | 会话日志与归档会话 |
| WorkBuddy | 完整用量（token） | 项目会话记录 |
| dsh (DeepSeek Harness) | 完整用量（token） | 压缩会话；桌面打包版如不在默认位置，需在高级配置中指定 |
| CatPaw | 仅活动量 | 本地只有会话/记忆痕迹，无 token 字段 |
| Trae CN | 仅活动量 | 其 ai-agent 数据库为加密存储，智账如实登记为「无法读取」 |

限制与口径：

- 「仅活动量」的工具只计入使用痕迹，**不会**折算成 token 或成本。
- 成本为**公开 API 参考价的等价估算**，人民币 / 美元分别显示、不换汇；
  无法确认价格时如实留空，不会算成「免费」。**估算不是实际账单。**
- 已入账的记录长期保留：AI 工具清理自己的历史后，账本里的记录仍在。
  反之，**首次读取之前**、或期间从未被智账读取过的记录，无法恢复。
- 智账只读取本机数据，不上传对话正文、代码或完整路径，无遥测、无云同步。

## 默认数据位置

| 内容 | 位置 |
|---|---|
| 账本 `usage.db` 与看板、配置、日志 | `%LOCALAPPDATA%\UsageLedger\`（或首次启动时自选的位置） |
| 账本位置指引文件 | `%LOCALAPPDATA%\PathOrbit\ZhiZhang\bootstrap.json` |

**卸载或升级都不会删除上述账本数据。**

## 更换 / 迁移账本位置

在 **设置 → 数据与隐私 → 账本保存位置 → 更改位置** 中启动迁移：

1. 选择一个**空的**目标文件夹（目标已有其他文件时，界面会要求另选空文件夹；
   已有一本智账账本时，可选择改用它，当前账本会原样保留在原位置）。
2. 迁移前智账会暂停账本更新（维护态），复制并逐一校验后切换到新位置；
   原位置的账本**完整保留，不会自动删除**。
3. 迁移中任何一步失败，智账都会留在原来的账本上继续可用，
   并给出失败原因；账本数据不会因此丢失。

## 升级与卸载

- **升级**：下载新版本安装包，安装到同一位置即可；账本数据不受影响。
  已安装版可在 **设置 → 关于** 中检查更新（默认在启动时自动检查，可随时关闭）；
  应用内更新经过签名验证，验签失败会拒绝安装。便携版用新版压缩包覆盖解压目录即可。
- **卸载**：卸载程序只移除程序文件，不删除账本数据目录。
- **退出后台**：右键系统托盘中的智账图标退出
  （若开启了「关闭主窗口后保持后台运行」）。

## 找不到支持的 AI 工具时

- 首次引导会如实提示「暂时没有发现可读取的 AI 工具」。
- 请先在支持列表中的工具里正常使用一次 AI，然后到
  **设置 → AI 工具 → 重新发现** 再检查一次。
- 高级用户也可以在数据目录中手动放置 `sources.json` 指定数据源路径
  （格式见仓库源码 `ledger.py` 内「数据源定义」一节的注释）；这是高级用法，
  普通用户不需要。
- **只使用网页版 AI（如 ChatGPT、豆包、千问网页版）的记录不在本机，
  智账目前无法记录这类使用**，请等待后续版本对更多客户端的支持。

## 已知限制（RC.6）

- 「打开应用时自动更新」尚未开放：更新账本目前是手动操作
  （侧栏按钮 / 设置页 / 托盘菜单）。
- 暂不支持合并两本账：目标位置已有一本账时，只能改用或另选位置。
- 成本为 API 等价估算，不是真实支付账单。
