## 产品与能力保持

产品仍是跨 AI 工具、按真实工作项目归账的个人 AI 使用总账。Project 是第一实体，Client / Source 是项目内来源维度。一级导航固定总览、探索、设置；首次使用是账本建立入口，项目 / 会话详情、项目整理、数据完整性使用叠层。没有额度卡片、重置倒计时、Provider 限额或新一级分析页。

Usage Ledger 是 V1 主体。Money Ledger 仅显示公开参考价格的 API 等价估算。实际 API 账单、订阅费、充值 / 预付、免费额度未来必须分开建模，不能复用一个 spend 字段。Plan Ledger 的领域架构保留，真实能力落地后另行评审。未来 Search / CSV / 完整定价与历史检查应进入现有探索和完整性区域。

## 页面行为

首次使用保留欢迎、查找、首次扫描、完成四阶段。按钮为开始查找 → 建立我的账本 → 查看总览。说明本机处理、自动汇入、项目归账；不要求用户学习 Token、RAW 或 collector。没有来源时说明支持工具与重试方式；只有使用痕迹也能建立账本，不编造具体用量。

总览标题「最近 AI 都用在哪？」。轻量数字栏顺序为参与项目、AI 会话、AI 使用量、估算成本。「我的项目」为最大主区；默认按使用量降序，可按人民币估算、美元估算、最近使用排序，币种不合并。行包含项目 / 最近使用、会话、用量、分币种估算、账本状态。模型分布默认折叠。右侧先回答完整性，再显示使用变化。

项目抽屉先展示最近使用、会话和工具、总用量、估算、完整性入口，会话按用量排序。「查看用量详情」展开输入、输出、缓存、模型和工具分布，其内高级信息保留原识别名、Kind、project_key 和路径片段。项目名称可修改但身份不变。会话抽屉保留首尾时间、项目、工具、模型、用量、估算、记录数和最近记录；助手、稳定会话身份及精确时间在技术来源中。详情操作固定在底部。

探索仍为项目 → 会话 → 使用记录，顶部明确当前路径。默认表格只有时间、AI 工具、模型、使用量、估算成本五列。点击记录展开输入、输出、缓存和精确值，再展开高级信息查看原始字段与 provenance。底部高级审计提供 EFFECTIVE / RAW / REPLAY，默认关闭；审计切换只影响当前记录列表，首页仍为有效用量。没有日志正文或调试控制台。

整理项目的三个标签为修改项目名称、归到正确项目、合并重复项目。移动与合并都保留选择、目标、预览、确认；名称的稳定身份说明折叠。更正账本关系不更改客户端原日志、目录或文件名。正式执行须原子保存、失败时保留旧关系、结果与预览一致，保留可追溯关系和撤回入口。此处演示不声称正式写接口已存在。

完整性详情先给可读结论，再分完整用量、部分记录、估算成本、历史完整性四组。来源健康、价格覆盖、未知记录和历史缺口是不同维度，不制造综合百分比。原始 / 回放 / 有效记录数量、定价 Token 分母、不可读存储和缓存语义仍在高级信息中。

设置七组：常用、AI 工具、更新账本、项目整理、数据与隐私、关于、高级。二级导航切换独立内容面，不再锚点滚动整套设置；页面本身为白色主内容面，无外层巨型卡片。常用只保留更新、自动更新状态、账本状态与数据位置，不重复完整工具清单。自动更新明确「尚未启用」，不显示假开关。普通描述 13–14px，导航为文字和细色条选中态。

AI 工具独立展示 5 个来源：三个可读完整使用量，CatPaw / Trae 为部分记录。更新账本展示最近时间、工具数量和真实示例结果，手动更新保留成功 / 部分成功 / 失败及防并发；启动与频率设置尚未启用。项目整理是管理名称 / 开始整理 / 管理合并三项具体动作；全账本待整理会话数与操作候选一致，不受首页筛选误裁剪，不声称发现重复项目。

数据与隐私分数据位置、隐私、历史账本；默认位置明确为打包模式示例，可环境覆盖。关于只显示已核对版本 0.10.0-beta.2、尚未取得的构建与数据格式身份，以及一句产品说明。高级统一收纳定价、缓存、RAW / EFFECTIVE / REPLAY、Schema、Runtime、Build ID、Backend、Data root 与诊断说明；默认折叠，隐私入口可直接展开存储说明。打开数据目录仍是示例提示，正式版必须由桌面接口打开真实 DATA_ROOT。

## 筛选、计量与身份契约

- 默认最近 30 天，支持今天 / 7 天 / 30 天 / 全部历史。今天按本地时区从 00:00 起；其他窗口与正式后端统一。示例时钟固定 2026-10-02 14:30 +08:00。
- 时间、项目、工具、模型联合筛选摘要、项目、会话、记录、模型、趋势和定价覆盖；必须筛选后聚合，再分页。不能用首批 50 条当完整候选集；返回同范围 total。
- 全部历史必须来自持久账本全历史，不把 board.window_days 的截断数据叫全部历史。缺少采集覆盖证据的趋势日期应断开或未知，不擅自补 0。母版零值来自完整的示例集。
- 工作项目数不含待整理分组；会话数可含仅活动会话。Activity 与 Token 分开，活动的具体用量和成本为 null，未知记录不是 0。
- input 为非缓存输入；WorkBuddy 为 max(prompt_tokens − cached_tokens, 0)。total_tokens = input + output，cache_read 单列，不加到 total。保留 Core 单一路径，不建第二套正式账本引擎。
- 默认 EFFECTIVE 排除已确认重放，RAW 永久保留；不把定价缺口、历史缺口、回放混为一种完整性。
- 参考价格是当前公开 API 等价估算，不是事件时点账单。CNY / USD 独立显示，不换汇、不相加。缺价格为 null，真实零价格才能显示 0。以已定价有效 Token / 全部有效 Token 为主覆盖证据，记录数辅助。
- Alias 只改 display_name，project_key 稳定。移动改会话归账关系；合并保留目标 key 并按原会话 / 记录身份去重。原 Project / Source / Session / Event provenance 可追溯。
- 源日志被清理后已入账历史仍保留；首次扫描前缺失不能声称补回。「未发现缺口」只代表可观测范围，不能证明全历史完整。

## 必要状态及恢复

所有下列状态有图标、标题、说明和下一步，而非仅改变颜色。

| 状态 | 反馈与下一步 |
|---|---|
| Loading | 正在打开账本；重新读取 |
| Scanning | 更新中，旧账本仍可读；查看已有记录 |
| Success | 账本已更新；查看项目 |
| Empty | 此范围无记录；清筛选 / 延长范围 |
| No source found | 未找到支持工具；说明支持列表、重新查找 |
| Partial success | 部分工具需检查；保留其他结果、查看详情 |
| Error | 读取或更新失败；历史保留、重新更新 / 读取 |
| No pricing | 使用量保留、价格暂不可估算；查看原因 |
| Unknown | 有记录暂无法识别；查看原因，不填伪 0 |
| Unassigned | 记录尚无所属项目；整理记录 |
| Disabled | 自动更新尚未启用；使用手动更新 |

另保留仅活动与历史缺口场景。扫描防并发，失败不吞历史。所有设计阶段扫描都是示例，不操作正式来源。

## 本轮 Final Lock 自检

1. Settings 是否取消大卡套大卡：是。白色页面作为内容面，Section 与极轻分隔线组织，不使用外层卡片。
2. 二级导航是否更轻：是。118 / 106 / 98px，细选中条与文字强调；一级侧栏不改。
3. 扫描是否统一为更新账本：设置界面已全部统一，内部数据标识 scan 不作为用户文案。
4. 常用是否只有高频项：是。更新、未启用自动更新、账本摘要、数据位置，无完整工具清单。
5. AI 工具是否一眼可懂：是。工具名、完整用量 / 使用痕迹说明、已找到 / 部分状态，不暴露解析器或内部路径。
6. 项目整理是否具体动作：是。管理名称、开始整理、管理合并，数量来自当前全账本示例，未编造重复发现。
7. 数据与隐私是否建立信任：明确本机保存、不上传完整路径、无遥测、无云同步与已入账历史保留，并解释默认位置。
8. 高级是否下沉：是。七分组中只有高级渲染工程信息，默认折叠；普通页的构建 / 数据格式身份使用中文简洁标签。
9. Primary CTA 是否减少：是。设置移除页头重复更新按钮，每个活动内容面至多一个金色主动作；叠层背景和空状态页头更新按钮降为次要视觉。
10. 字号是否适合阅读：设置描述 13–14px，关键表头 / 项目副信息 / 抽屉次级文字至少 12px；复核四档窗口。没有实际用户长时间使用研究。
11. 其他页面是否误重构：没有。First Run 内容与流程原样保留；Overview / Drawer / Explore / 整理 / 完整性只做允许的视觉收口，计量与下钻保持。
12. Runtime 是否修改：NO。仅写原 design/functional-v1-master，219 个 Runtime / 生产文件哈希及 Git 差异有独立报告。
